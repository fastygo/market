# Load test 2026-11-25: performance and memory hardening

Harness: `scripts/loadtest` (README there). Seed: 10 000 products, 500 sellers,
12 categories, 50 users. Server pinned to one CPU with `GOMAXPROCS=1`
(emulates the 1 vCPU host); the client ran on other CPUs. Closed loop,
16 workers (saturation) and 1 worker (service time).

"Before" = 38ff422 (free-checkout fix only). "After" = c041bd0 plus later.

## Findings

- FTS5 is compiled into modernc.org/sqlite v1.60.1 (SQLite 3.53.4), with
  the `unicode61` and `trigram` tokenizers (pinned by `pb/fts5_test.go`).
  `unicode61 remove_diacritics` does not fold Cyrillic yo (U+0451) into ie (U+0435).
- goja/jsvm is not linked (`go list -deps`, go.sum), so there is no JS VM
  heap risk today.
- Free checkout bug: `provider_payment_id` was the constant `"free"`, so
  the unique index allowed one free order per shop. Fixed in 38ff422.
- Stale planner stats: after a bulk import `sqlite_stat1` still described
  the seed catalog and the planner chose `SCAN sellers x SCAN products` plus
  a temp b-tree: 2.4 s per catalog page, 1 RPS. PocketBase only runs
  `PRAGMA optimize` nightly. Readers keep the stats they loaded at open.
  Fixed by the `CROSS JOIN` order hint, id filters, composite indexes,
  `OptimizeDB` at start and hourly, and recycling idle readers.
- RSS vs heap: Go heap stays about 12 MB; RSS is SQLite memory (page cache
  per connection, in-memory temp b-trees). The pool of 120 connections
  reached 605 MB; capped at 8 it is 290-390 MB, 140 MB with a 4 MiB cache.
- CPU: `utils.mergeTailwind` (UI8Kit, vendored under `ui/kit`) is 43% of CPU
  on list pages; a 100-card render costs about 20 ms. Not changed here
  (UI8Kit rules); memoizing it upstream is the biggest remaining win.
- Goroutines: 22 idle, 39 under load, 23 after clients closed (no leak).
  Graceful shutdown took 151 ms.

## SLO thresholds (from these numbers, 1 vCPU)

- Catalog and category pages: p95 <= 300 ms, p99 <= 800 ms.
- Product and author pages: p95 <= 100 ms.
- Search: p95 <= 300 ms at moderate load.
- Free checkout: p95 <= 300 ms; `market_tx_lock_wait_seconds` p99 < 200 ms.
- 5xx share: 0 in every run; alert above 0.5%.
- RSS alert at 450 MB with `GOMEMLIMIT=512MiB`.
